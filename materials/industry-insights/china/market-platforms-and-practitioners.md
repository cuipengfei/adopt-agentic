# 中国市场卷：企业落地、平台能力与一线实践者

> 聚焦中国语境下的 agentic AI 编码实践：个人实践者、企业落地与平台治理。

---

## 来源 M：中国市场补充（本土实践者 + 企业落地）

### 刘小排（独立开发者 / AI 创业者）

**洞见 1：先写需求文档，再让 Agent 复述和出方案，最后才编码**

- 高强度 AI Coding 下，最常见问题不是“写不出来”，而是“写成屎山”；可复用做法是：先写较完整需求（常见 1000-2000 字），要求 Agent 先复述理解并提出决策点，再进入实现。
- 关联节点：1 上下文(Context)、3 System Instructions、8 Eval/验证
- 来源：播客《揭秘 Claude Code 榜一大哥：一个 AI 创业者如何把工具用到极致｜对话刘小排》（十字路口 Crossing，2025-08-31）

**洞见 2：把 Agent 当“可编排劳动力”，而不是单次补全工具**

- 强调 background commands、子 Agent、7x24 持续运行等长任务能力，典型模式是“人定义目标与验收，Agent 持续执行并回传结果”。
- 关联节点：4 内置工具(Tools)、9 Sub Agents
- 来源：同上播客（2025-08-31）；腾讯新闻整理（2025-08-20）

**洞见 3：模型分工优于单模型硬扛**

- 更倾向“长上下文模型做架构讨论 + coding agent 做执行落地”，把模型差异转为角色分工。
- 关联节点：2 三角关系、9 Sub Agents
- 来源：同上播客（2025-08-31）

### 有赞技术团队（企业内研发流程落地）

**洞见 1：企业落地不是“一个插件”，而是研发全流程改造**

- 将 AI 能力覆盖到需求、设计、编码、测试、上线，形成 AI Coding + AI Test + AI DevOps 组合落地。
- 关联节点：2 三角关系、8 Eval/验证
- 来源：《有赞 AI 研发全流程落地实践》（有赞技术，掘金，2026-01）

**洞见 2：组织角色从“直接产出”转向“算力与流程编排”**

- 人的关键价值转向任务拆解、风险把控、流程设计与质量验收。
- 关联节点：0 介绍、2 三角关系

### 腾讯云代码助手企业版（本土企业约束）

**洞见 1：高合规行业优先私有化 / 离线 / 专网部署**

- 企业版资料强调客户自有 IDC、离线部署、专属网络访问与国产算力适配。
- 关联节点：4 内置工具(Tools)、8 Eval/验证
- 来源：腾讯云《代码助手企业版产品资料》（2026-02 检索）

**洞见 2：AI 采用要与研效治理绑定**

- 成员统计、授权管理、研效看板等能力说明企业采购重视“可治理 + 可量化 ROI”。
- 关联节点：8 Eval/验证

### 中国机构实践（信通院 + 华为云）

**洞见：大规模落地难点在工程化与集成，不在 Demo 可用性**

- 《智能化软件开发落地实践指南》将挑战聚焦在模型选型、工程化建设、流程集成与落地路径。
- 关联节点：8 Eval/验证
- 来源：《智能化软件开发落地实践指南（2024）》

### 中国基模与 Agent 路线讨论（AGI-Next）

**洞见：ToC/ToB 价值逻辑分化，ToB 更依赖高质量上下文与高可靠执行**

- 公开报道观点集中在：Context、模型上限与可验证性共同决定商业价值；弱模型在严肃生产场景隐性排障成本高。
- 关联节点：1 上下文(Context)、8 Eval/验证
- 来源：AGI-Next 峰会公开报道（2026-01-10）

## 使用建议（面向 Phase 2 写作）

1. **人物段落写法**：用“人物观点 + 可执行方法 + 节点映射”三段式，避免只写“谁说了什么”。
2. **证据优先级**：官方文档 > 本人长文/访谈 > 媒体转述。
3. **中国市场差异化**：强调“私有化/专网/审计/研效治理/组织重构”五个关键词。
