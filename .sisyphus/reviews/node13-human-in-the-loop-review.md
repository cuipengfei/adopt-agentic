# Review: 节点 13 — Human-in-the-Loop

## 总评
当前 draft 整体质量高：结构清晰、双语基本等效、可执行框架已经成形。主要短板是：**上下文主线在正文中不够"硬连接"**、**"放手 vs 介入"还可再量化**、以及少量语气偏"教导式"。
**Effort estimate：Short（1–4h）**

## 逐维度

1. **写作风格（十人混血儿）**：**通过，但可再收刀锋**。有框架感和落地性，但个别比喻略"戏剧化"（如"核潜艇发射钥匙"）。保留类比但换成更工程化表达。

2. **精简度**：**中上**。开头有轻微重复（"你不是观众""你是决策者""方向盘在你手里"语义重叠）。压缩成 2 句。

3. **上下文主线：人决定上下文最终走向**：**有点到，但正文承载不足**。中段缺少"每次批准/拒绝/修改如何改写下一轮 context"的硬连接。加一条公式句：`Decision -> Context Mutation -> Next Agent Behavior`。

4. **放手 vs 介入判断标准**：**80% 到位**。风险表很好，但边界仍偏经验化。补 3 个硬触发器（external write、irreversible action、high-cost execution）。

5. **认知债务子项**：**核心观点准确**。定义清楚，给了三种缓解手段。再补"症状指标"（解释不了关键模块、review 时间持续上升、故障定位依赖 agent 复述）。

6. **不说教**：**基本达标，但可再去命令口吻**。"你需要…/记住…"改成条件式与权衡式句型。

7. **Agent Agnostic**：**通过**。把"好的 Agent 工具会默认…"改为"部分工具会默认…"。

8. **中英文质量对等**：**高对等**。仅做微调级同步。

9. **横切关注点**：**齐全且有效**。可把"可审计性"再落一条最小实践。

10. **与前后节点衔接**：**可读，但"桥"不够显式**。加两句：
   - 承上：`Eval 告诉你"结果对不对"，Human-in-the-Loop 决定"下一步往哪走"。`
   - 启下：`即便进入多 Agent 协作，人类仍是最终上下文仲裁者。`
